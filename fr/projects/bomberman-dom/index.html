Bomberman DOM

▶ APPUYEZ SUR START

Un Bomberman multijoueur pour 2 à 4 joueurs dans le navigateur. Pas de canvas ni de WebGL : tout le jeu est fait d'éléments DOM, rendus par un mini-framework que nous avons écrit nous-mêmes et animés avec requestAnimationFrame à 60 fps. Les joueurs se retrouvent dans un lobby avec minuteurs, discutent en temps réel, ramassent des bonus et ont 3 vies chacun.

OBJETS

  • JavaScript
  • WebSockets
  • Own mini-framework
  • requestAnimationFrame
  • HTML & CSS
