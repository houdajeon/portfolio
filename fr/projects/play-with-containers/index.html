Play with Containers

Des microservices derrière une API gateway, empaquetés avec des Dockerfiles optimisés et reliés par Docker Compose.

Un système de microservices conteneurisé de zéro : une API gateway, des services applicatifs, des bases PostgreSQL et une file RabbitMQ, le tout démarré avec Docker Compose. J'ai écrit les Dockerfiles, configuré les réseaux et les volumes, et documenté comment tout lancer.
