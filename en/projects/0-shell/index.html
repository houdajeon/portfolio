0-shell$ cat README

A minimalist Unix-like shell written in Rust and inspired by BusyBox, built as a team of 4. It shows a prompt, reads and parses each line, and runs the commands itself through system calls, without bash, sh or any external binary. It ships 13 commands, including ls with -a, -F and -l, and keeps a command history.

The problem

Embedded Linux systems often can't ship a full shell and its utilities. The goal was a small standalone shell that handles navigation, file manipulation and process control on its own, while behaving like the shell people already know.

What it does

  • A read, parse, run loop with its own prompt
  • 13 commands written in Rust: echo, cd, ls, pwd, cat, cp, mv, rm, mkdir, exit, clear, help, history
  • ls with -a, -F and -l: permissions, owner, size, date and device numbers
  • rm -r for directories
  • Quoted arguments, with a continuation prompt while a quote is still open
  • Command history saved to a file
  • Tests for ls on regular files, directories, symlinks and executables

Key technical challenges

  • Sending each command to the right code

    error
    Every line typed has to reach the right implementation, and an unknown name must not crash the shell.
    fix
    A dispatcher built on a HashMap from command names to function pointers. An unknown name prints Command Not Found and the prompt comes back.

  • Rebuilding ls -l without the real ls

    error
    Every column has to be computed by hand: the permission string, owner and group, size, modification date, and device numbers for special files.
